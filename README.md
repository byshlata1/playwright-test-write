# Playwright Recorder

Chrome Extension (Manifest V3) для записи действий и API-запросов с генерацией Playwright-тестов и моков.

## Установка

1. Откройте `chrome://extensions/`
2. Включите «Режим разработчика»
3. Нажмите «Загрузить распакованное расширение»
4. Выберите папку `playwright-test-write`

## Использование

1. Откройте любую страницу
2. Откройте DevTools (F12)
3. Перейдите на вкладку **Playwright Recorder**
4. Нажмите **Start Recording**
5. Выполните действия на странице (клики, ввод, выбор)
6. Extension перехватит fetch/XHR и сохранит ответы как моки
7. Нажмите **Stop Recording**
8. Просмотрите сгенерированный тест, нажмите **Copy** и сохраните в `test.spec.ts`
9. Создайте папку `mocks/` и сохраните JSON-моки по инструкциям

## Поддерживаемые действия

- `click` — клик по элементу
- `doubleClick` — двойной клик
- `rightClick` — клик правой кнопкой (контекстное меню)
- `fill` — ввод текста
- `selectOption` — выбор опции
- `check` / `uncheck` — чекбоксы
- `press` — нажатие клавиш (Enter, Tab, Escape, F1–F12, Ctrl+C и т.п.)
- `hover` — наведение курсора (Shift+1)
- `scroll` — прокрутка до элемента (Shift+2)
- `goto` — переход на новый URL (клик по ссылке, редирект после формы и т.п.)
- `dragTo` — перетаскивание элемента
- `setInputFiles` — загрузка файла (input type="file")

## Инструкция для пользователей

### Разделы панели DevTools

| Раздел | Описание |
|--------|----------|
| **Status** | Текущее состояние: Ready, Recording... или Waiting for requests... |
| **Folder picker** | Подсказка: Save открывает новую вкладку для выбора папки сохранения |
| **Controls** | Кнопки Start, Stop, Clear — запуск/остановка записи, очистка |
| **Stats** | Счётчики: Actions, Mocks, Failed — сколько действий записано, моков, ошибок |
| **Failed Requests** | Список запросов, которые завершились ошибкой (появляется при наличии) |
| **Mocks** | Автоматически перехваченные fetch/XHR-ответы. Можно редактировать (Edit) |
| **Actions** | Записанные действия. Чекбокс «Capture all clicks» и кнопка «Add to test» |
| **Export** | Имя теста, Generate, Save — генерация и сохранение кода |
| **Preview** | Готовый Playwright-код — выделите и Ctrl+C для копирования |

### Как записывать действия

#### Автоматически (без сочетаний клавиш)

- **Клик** — просто нажимайте на кнопки, ссылки и др.
- **Двойной клик** — два быстрых клика по элементу
- **Правый клик** — клик правой кнопкой мыши
- **Ввод текста** — печатайте в `input` и `textarea`
- **Выбор опции** — меняйте значение в `<select>`
- **Чекбоксы** — ставить/снимать галочку
- **Клавиши** — Enter, Tab, Escape, F1–F12, Ctrl+C, Ctrl+V и т.п.
- **Файл** — выберите файл в `<input type="file">` (путь в коде — placeholder, замените на реальный)
- **Перетаскивание** — зажмите элемент и отпустите на другом

#### Hover (наведение курсора)

**Сочетание клавиш:** `Shift+1`

1. Наведите курсор на нужный элемент
2. Нажмите сочетание клавиш
3. Hover будет записан для элемента под курсором

В сгенерированном тесте появится строка вида:
```js
await page.locator('селектор').hover();
```

#### Scroll (прокрутка до элемента)

**Сочетание клавиш:** `Shift+2`

1. Наведите курсор на элемент, до которого нужно прокрутить
2. Нажмите сочетание клавиш
3. Будет записан `scrollIntoViewIfNeeded` для этого элемента

```js
await page.locator('селектор').scrollIntoViewIfNeeded();
```

#### Goto (переход по ссылке)

Записывается **автоматически**: при клике по ссылке или редиректе (например, после отправки формы) расширение фиксирует новый URL и добавляет шаг:
```js
await page.goto('https://...');
```

#### «Capture all clicks»

По умолчанию записываются клики только по интерактивным элементам (кнопки, ссылки, label и т.п.). Если включить **Capture all clicks**, будут записываться клики по любым элементам (например, по `<div>` или `<span>`).

#### Add to test

Кнопка **Add to test** переносит текущий список Actions в итоговый тест. Используйте её, когда нужно зафиксировать группу действий как часть теста, не останавливая запись.

### Порядок работы

1. Start → выполняйте действия на странице
2. По мере необходимости — Add to test (опционально)
3. Stop → просматривайте Preview, копируйте код
4. Сохраняйте моки в папку `mocks/` по инструкциям в сгенерированном коде

## Приоритет локаторов

При генерации селекторов используются следующие методы в порядке приоритета:

| Приоритет | Метод         | Почему                                                 |
| --------- | ------------- | ------------------------------------------------------ |
| 1         | `getByTestId` | Явный контракт от разработчиков, не ломается от рефакторинга |
| 2         | `getByRole`   | Тестирует accessibility, устойчив к изменениям дизайна (name ≤ 60 символов) |
| 3         | `getByLabel`  | Семантика форм, понятно пользователям                  |
| 4         | `getByText`   | Понятно, но текст меняется часто (≤ 60 символов)       |
| 5         | CSS/XPath     | Только как fallback                                    |

Пример сгенерированного кода с `getByRole`:
```js
await page.getByRole('button', { name: 'Submit' }).click();
await page.getByLabel('Email').fill('user@example.com');
await page.getByTestId('submit-btn').click();
```

### Подсветка элементов (Live Highlight)

Во время записи при наведении курсора на любой элемент страницы:
- Элемент подсвечивается синей рамкой
- Рядом появляется тултип с выбранным методом локатора и цветным бейджем (ROLE / LABEL / TEST-ID / TEXT / CSS)

## MVP-ограничения

- Только показ кода и инструкций (без JSZip)
- goBack / goForward не поддерживаются
- Моки хранятся в памяти сессии
